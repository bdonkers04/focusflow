# FocusFlow

A polished, responsive landing page for a fictional productivity platform. Built as a front-end portfolio project with a product dashboard mockup, dark/light themes, mobile navigation, pricing, and accessible FAQ interactions.

## Highlights

- Responsive layout for desktop, tablet, and mobile
- Interactive color theme and navigation
- Semantic, keyboard-friendly interface
- Reduced-motion support
- Product-focused visual storytelling
- Production-ready build and deployment configuration

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
```
